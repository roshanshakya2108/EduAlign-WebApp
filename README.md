# EduAlign-WebApp

EduAlign-WebApp is an AI-powered web application designed to analyze school infrastructure and optimize resource allocation. It helps identify schools with non-standard structures, predicts their infrastructure needs, and provides data-driven recommendations to improve efficiency.

## Features

- **AI-Powered Prediction**: Uses a trained machine learning model to assess school infrastructure and predict the need for resource allocation.
- **Data-Driven Insights**: Analyzes key metrics such as student-teacher ratio, available classrooms, libraries, and computer labs.
- **Dynamic Resource Allocation**: Recommends restructuring plans to enhance school infrastructure and optimize resource distribution.
- **Interactive Dashboard**: Visualizes school performance, infrastructure scores, and allocation requirements for better decision-making.
- **Stakeholder Collaboration**: Facilitates communication between government officials, NGOs, and educational institutions to improve school facilities.

## Installation & Setup

To set up the project, clone the repository, create a virtual environment, install dependencies, and run the Flask application. An alternative interactive dashboard is available using Streamlit.

## Dataset

The application uses a dataset containing details about school infrastructure, including student and teacher counts, classroom availability, technological facilities, and performance scores. The trained machine learning model processes this data to classify schools and provide actionable insights.

## Machine Learning Model

The project utilizes a Random Forest model trained to predict infrastructure needs. The model is stored in a pickle file and is used to make real-time predictions within the web application.

## Future Enhancements
